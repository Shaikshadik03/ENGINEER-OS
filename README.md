## 🎯 The Vision

Right now, a B.Tech student's life is fragmented across:
- 📚 College portal (for syllabus)
- ▶️ YouTube (for lectures)
- 💻 LeetCode (for DSA)
- 📋 Trello (for tasks)
- 💼 LinkedIn (for networking)
- 🔍 Internshala (for jobs)

**Engineer OS replaces all of them.** It is an AI-powered, glassmorphic, premium SaaS platform where a student lives from Semester 1 to graduation — guided every step of the way by a powerful AI engine that knows their skills, their goals, and their career path.

## ✨ Features (Full Vision)

<details>
<summary><b>🧠 AI Profile Engine — The Brain of the OS</b></summary>
<br/>

The student fills out a deep profile: **Branch, Semester, Mastered Skills, Currently Learning, and Interests**. This data powers everything else on the platform. The AI uses it to:

- Calculate accurate **Job Match Scores** (e.g., "96% match — you have React & Node.js")
- Auto-recommend **Daily Tasks** based on their active roadmap
- Surface the **right roadmap** for their career goal
- Filter **real, verified opportunities** (no scam postings)

</details>

<details>
<summary><b>📖 University Syllabus Engine — Drill Down to Every Topic</b></summary>
<br/>

Select your Branch and Semester. The OS presents your exact subjects, chapters, and sub-topics. Inside every sub-topic:

- 📺 **Video Lectures** (curated, embedded)
- 📝 **Written Notes** (structured text)
- 🎯 **Practice Quiz** (+XP for passing)

**Branches covered:** CSE · IT · ECE · EEE · AIML · Data Science

**Depth:** Semester → Subject → Chapter → Sub-topic → Content

Example: `CSE` → `Sem 3` → `Data Structures` → `Trees` → `AVL Trees` → `[Video] [Notes] [Quiz]`

</details>

<details>
<summary><b>🛤️ Visual Career Roadmaps — Skill Trees with Node-Based UI</b></summary>
<br/>

Visual, interactive roadmaps for every major tech career:

| Role | Key Nodes |
|------|-----------|
| Full Stack Developer | HTML → CSS → JS → React → Node → Databases → Deployment |
| Data Scientist | Math → Python → SQL → ML → Deep Learning → Model Deployment |
| Android Developer | Kotlin → Android Studio → Compose → MVVM → Play Store |
| DevOps Engineer | Linux → Docker → CI/CD → Kubernetes → AWS → Monitoring |
| ML Engineer | Python → ML Algos → PyTorch → NLP → Computer Vision → MLOps |
| Cybersecurity | Networking → Linux → Cryptography → Pen Testing → Incident Response |

Nodes show `✅ Completed`, `⏳ In Progress`, or `🔒 Locked` based on real progress.

</details>

<details>
<summary><b>📚 Tech Skills Library — Every Skill, Every Sub-topic</b></summary>
<br/>

A massive library of skills with deep curriculum:

- **Python** — Basics, OOP, Data Structures, Decorators, Ecosystem
- **Java** — JVM, OOP, Collections Framework, Streams, Lambdas
- **JavaScript** — ES6, DOM, Async/Await, Closures, Prototype Chain
- **React.js** — JSX, Hooks (useState, useEffect, useMemo), Context, Redux
- **Node.js** — Event Loop, Express, Auth (JWT), REST APIs
- **DSA** — Arrays, Linked Lists, Trees, Graphs, Dynamic Programming
- **SQL** — Basic Queries, Joins, Window Functions, Normalization
- **AI/ML** — Linear Algebra, Scikit-Learn, Neural Networks, TensorFlow
- **Communication** — Cover Letter, STAR Method, Interview Prep

Every sub-topic has: `Video Lecture · Written Notes · Quiz (+XP)`

</details>

<details>
<summary><b>💼 Opportunities Board — AI-Filtered. No Fake Listings.</b></summary>
<br/>

A strict, AI-filtered board for:
- 🏆 **Hackathons & Coding Contests**
- 📋 **Internships** (with stipend filter)
- 💼 **Full-Time Jobs**
- 🏫 **Tech Events & Workshops**

Every listing shows a **circular AI Match Score** calculated by comparing the job's required tech stack against the student's profile. A React+AWS job scores 95%+ for a student who knows both.

Filters: Role · Location · Salary · Match% · Remote Only · Type

</details>

<details>
<summary><b>🗂️ Kanban Task Manager — AI Recommends Your Daily Goals</b></summary>
<br/>

An interactive drag-and-drop Kanban board:
- Columns: `To-Do · In Progress · Done`
- **Add/Edit/Delete tasks** with categories and deadlines
- **AI Task Recommendations** — based on the student's active roadmap, the AI suggests daily actions (e.g., *"You're learning React. Task: Build a todo app today."*)

</details>

<details>
<summary><b>📅 Editable Calendar</b></summary>
<br/>

A full monthly/weekly grid where students can click any day and add:
- 📌 Urgent Meetings
- 📝 Exam Deadlines
- 🏆 Hackathon Schedules

Color-coded by type. Always visible from the dashboard.

</details>

<details>
<summary><b>📊 Analytics Dashboard — Data Scientist-Level Insights</b></summary>
<br/>

Charts built with Recharts:
- **Candlestick Chart** — Daily coding productivity
- **Radar Chart** — Skill mastery (Frontend, Backend, DSA, Core CS, Soft Skills)
- **Line Graph** — XP and task completion over 6 months

</details>

<details>
<summary><b>🚀 Startup Scout — Find Co-Founders. Pitch Your Idea.</b></summary>
<br/>

A networking hub for builder-students:
- Browse startup pitches from other students
- Cards show: Stage (Idea, MVP, Seed) · Founder · Description · "Looking For" tags
- **Pitch Your Idea** form to recruit your technical team

</details>

<details>
<summary><b>📰 Tech News Feed — Stay Relevant, Not Outdated</b></summary>
<br/>

A daily curated Perplexity-style feed covering AI, Web3, Tech Jobs, and Engineering trends. Large images, short AI summaries, "Deep Dive" button for full articles.

</details>

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- A [Supabase](https://supabase.com) account (free)

### 1. Clone the repo
```bash
git clone https://github.com/Shaikshadik03/Engineer-OS.git
cd Engineer-OS
npm install
```

### 2. Set up environment variables
Create a `.env.local` file in the root:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
```

### 3. Set up the database
Run the SQL in `supabase_schema.sql` inside your Supabase **SQL Editor**.

### 4. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — you will be redirected to the signup flow.
